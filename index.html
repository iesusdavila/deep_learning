How it works

01
Pick a concept.
Pick any module. Each one stands alone — start anywhere.
02
Manipulate the inputs.
Drag sliders, modify matrices, add layers, swap activations. The visualization recomputes on every frame.
03
Read the math.
Equations live alongside every visualization. Toggle them on/off, hover for derivations.
04
Chain it together in the Sandbox.
When you're ready, drop modules onto a canvas and connect them. Build a real CV pipeline.
