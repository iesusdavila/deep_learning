DINO. Learning to see
with no labels at all.

CLIP needs captions. Supervised models need class labels. DINO needs nothing — just images. It teaches a network to agree with itself across different crops of the same picture. The shocking result: attention maps that segment objects emerge on their own, never having been told what an object is.

Why doesn't it cheat? If student and teacher were identical and free, both could output a constant and the loss would be zero — total collapse. DINO blocks this two ways: the teacher is a momentum average (it changes slowly, giving a stable target) and its outputs are centered (subtract a running mean) and sharpened (low temperature). Try breaking it in §3.

MOMENTUM λ 0.9960
Student weights (yellow) jump around each step; teacher (magenta) is their slow trailing average. Higher λ → smoother, more stable target, slower to adapt.
// 02

Multi-crop · global views for the teacher, local for the student

CROP STRATEGY 2 global + 6 local
THE CROPS EACH NETWORK RECEIVES
Global crops (large, 224²) go to teacher. Local crops (small, 96²) go to student. The student must predict the teacher's "big picture" view from a tiny fragment — forcing it to learn part-to-whole relationships.
The intuition → A local crop of a cat's ear must produce the same representation as the global crop of the whole cat. To pull that off, the student learns "this ear belongs to this kind of object" — semantic structure, from geometry alone.

The payoff · emergent attention segmentation

Where this leads → DINOv2 scaled this recipe to produce general-purpose visual features that work — frozen, no fine-tuning — for depth, segmentation, retrieval, and classification. Self-supervision is now the default way to pretrain a vision backbone when labels are scarce.
